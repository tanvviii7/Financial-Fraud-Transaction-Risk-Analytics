## Financial Fraud & Transaction Risk Analytics

## Project Overview
An end-to-end financial fraud analytics project built using Power BI, SQL, and Python to analyze transaction patterns, identify fraud risks, and evaluate fraudulent transaction activity.

## Business Objectives
- Measure transaction volume and overall fraud rate.
- Analyze fraud patterns across payment methods and transaction channels.
- Compare fraud rates by device status, region, and merchant category.
- Identify transaction hours associated with higher fraud rates.
- Analyze monthly transaction activity and fraud trends.
- Evaluate fraud rates across transaction amount bands.

## Tools & Technologies
- **Power BI:** Interactive dashboard and KPI visualization
- **SQL (MySQL):** Data analysis, aggregation, and data-quality checks
- **Python:** Data cleaning, exploratory analysis, and results generation
- **Microsoft Excel:** Dataset preparation and analytical outputs

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Transactions | 6,000 |
| Fraudulent Transactions | 228 |
| Fraud Rate | 3.80% |
| Total Transaction Value | ₹15.64M |
| Fraudulent Transaction Value | ₹583.59K |

## SQL Analysis
SQL was used to analyze transaction records, summarize fraudulent transactions, compare fraud rates across business dimensions, review transaction trends, and perform data-quality checks.

## Python Analysis
Python was used for data preparation, exploratory data analysis, fraud-related aggregations, and generating analytical results.

## Key Findings
- The dataset contains 6,000 transactions, of which 228 are labelled as fraudulent.
- The overall fraud rate is 3.80%.
- Fraud patterns vary across payment methods, transaction channels, device statuses, and regions.
- Transaction-hour and monthly trend analysis provides insight into transaction activity.
- Transaction amount bands help compare fraud rates across transaction sizes.

*Note: These findings describe patterns in the dataset and do not establish causal relationships.*
